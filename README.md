# 🎯 파이썬 콘솔 퀴즈 게임 (Quiz Game)

터미널에서 손쉽게 즐길 수 있는 객체지향 기반의 파이썬 퀴즈 게임 프로젝트입니다.

---

## 📌 1. 프로젝트 개요
- 본 프로젝트는 파이썬 기초 문법과 객체지향(OOP) 개념, 그리고 JSON 기반 데이터 입출력(영속성)을 학습하기 위해 제작되었습니다.
- 사용자 입력을 기반으로 퀴즈 풀기, 새로운 퀴즈 등록, 퀴즈 목록 조회, 최고 점수 확인 기능을 제공합니다.

---

## 💡 2. 퀴즈 주제 및 선정 이유
- **퀴즈 주제**: 파이썬 기초 문법 및 개발 상식
- **선정 이유**: 개발 입문 단계에서 필수적으로 알아야 할 파이썬의 기본 개념(자료형, 함수, 출력 방식 등)을 복습하고, 이를 퀴즈 형태로 재미있게 풀어내기 위해 해당 주제를 선정했습니다.

---

## 🚀 3. 실행 방법

### 요구 사항
- Python 3.10 이상

### 실행 명령
터미널(또는 VS Code 터미널)에서 아래 명령어를 입력하여 프로그램을 실행합니다.


python main.py

---

## 4. 주요 기능 목록

📝 퀴즈 풀기:  저장된 퀴즈를 순서대로 하나씩 풀이합니다.  각 문제마다 4개의 선택지가 제공되며, 정답 번호(1~4)를 입력합니다.  풀이가 끝나면 정답 개수와 최종 점수가 출력되며, 최고 점수 달성 시 자동으로 기록이 갱신됩니다.  

📌 퀴즈 추가:  사용자가 원하는 새 문제, 선택지 4개, 정답 번호를 직접 입력하여 추가할 수 있습니다.  입력값 검증을 통해 빈 값이나 범위 밖의 숫자가 들어오는 것을 방지합니다.  

📋 퀴즈 목록 보기:  현재 등록되어 있는 모든 퀴즈의 문제 제목 목록을 조회합니다.  

🏆 점수 확인:  현재까지 기록된 최고 점수와 당시 맞힌 문제 수를 확인할 수 있습니다. 

⚠️ 예외 처리 (공통):

숫자 이외의 문자 입력, 공백 입력, 범위 밖 숫자에 대해 오류 메시지를 출력하고 재입력을 유도합니다.

Ctrl+C 등으로 강제 종료 시에도 프로그램이 비정상 종료되지 않고 안전하게 메시지를 출력하며 종료됩니다.

## 📁 5. 프로젝트 파일 구조

quiz_game/

├── quiz.py        # 개별 퀴즈 정보(문제, 선택지, 정답)를 관리하는 Quiz 클래스

├── game.py        # 게임 진행 로직 및 JSON 입출력을 담당하는 QuizGame 클래스

├── main.py        # 메뉴 출력 및 프로그램 시작을 담당하는 메인 실행 파일

├── state.json     # 퀴즈 데이터 및 최고 점수가 저장되는 JSON 파일 (자동 생성)

└── README.md      # 프로젝트 설명 및 사용 문서
